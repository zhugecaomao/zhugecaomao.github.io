# zhugecaomao.github.io

GitHub Pages 个人主页: 把 https://zhugecaomao.github.io 和大小写不同的 `/altrun` 等地址转到 [ALTRun 官网](https://zhugecaomao.github.io/ALTRun/)。

- `index.html`: 根地址跳转到 `/ALTRun/`
- `altrun/index.html`: `/altrun` 跳转到 `/ALTRun/` (项目网站的路径区分大小写)
- `404.html`: 其它不存在的地址 (例如 `/Altrun/xxx`) 按原路径转到 `/ALTRun/...`, 不认识的转到首页

ALTRun 官网的源码在 [zhugecaomao/ALTRun](https://github.com/zhugecaomao/ALTRun) 的 `site/`。
